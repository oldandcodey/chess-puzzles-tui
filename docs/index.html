Chess Puzzles

A terminal trainer for mate-in-N endings. It shows the position, you set it up on a real board, solve it against a timer, then grade yourself. Fixed-width ASCII, so it stays aligned over SSH.

MIT MSRV 1.85 SSH-friendly 300 Lichess puzzles CC0 data

Features

  • Mate in 1, 2, or 3. Each level keeps its own place in the pack.
  • ASCII board with white at the bottom, plus a piece list for setting up a physical board.
  • Timer defaults 1:00 / 3:00 / 5:00. Step by 30 seconds, from 0:30 to 30:00.
  • Amber under 10 seconds, red overtime. The clock does not auto-fail you.
  • H shows only the first move. R reveals the line and stops the clock.
  • Self-grade: solved, second try, hint, or missed. Session tallies stay in memory until quit.

Build & run

git clone https://github.com/oldandcodey/chess-puzzles-tui.git
cd chess-puzzles-tui
chmod +x play
./play
cargo test

The pack is data/puzzles.json, read relative to the working directory. ./play cds to the project root first. Over SSH, export TERM=xterm-256color if the colors look off.

Puzzle pack

300 puzzles, 100 each of mate in 1, 2, and 3, ratings spread from 600 to 2000. Built once from the Lichess open database, which is released under CC0. Thank you, Lichess. Each row links back to https://lichess.org/training/ plus the puzzle id.
